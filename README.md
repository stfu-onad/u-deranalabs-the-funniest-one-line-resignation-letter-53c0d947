# The Funniest One-Line Resignation Letter

The one-line resignation letter of a cron job: it has fired every minute
since March, never once been thanked, and HR still calls it "the cron thing".

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` validates the entry (1–140 characters, one line, not only
whitespace) and writes it plus a trailing newline to `/output/entry.txt`.
